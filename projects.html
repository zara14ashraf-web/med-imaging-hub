PROJECT 01

X-ray Quality Control Classifier

Vision Transformer (ViT) • Automated X-ray Image Quality Assessment

The idea

Image quality is an important part of radiography. Problems such as blur, exposure errors, or unwanted artifacts can affect the usefulness of an X-ray image and may require additional review or repeat imaging.

I developed this project to explore whether Artificial Intelligence could provide an early quality-control assessment of X-ray images before they move further through the imaging workflow.

What I built

The system uses a Vision Transformer (ViT) to classify X-ray images into four quality categories: Good Quality, Blur, Exposure Error, and Foreign Artifact.

The project was developed as an end-to-end workflow, including dataset curation, image review, preprocessing, augmentation, model training, model comparison, evaluation, model hosting, and deployment as an interactive Streamlit application.

Model Vision Transformer
Images 1,866 X-ray Images
Classes 4 Quality Categories

Dataset curation

Rather than relying on a single ready-made dataset, I curated the dataset myself from multiple publicly available X-ray image sources and collections. This involved collecting, reviewing, organizing, and assigning images to the four target quality categories.

This part of the project was especially important to me because the work was not limited to training a model on an existing dataset. Preparing the data itself became part of the learning process and the overall project development.

Results

96.08% Validation Accuracy
92.31% Test Accuracy
100% Blur Recall
100% Artifact Recall

The final model achieved 92.31% test accuracy on the evaluated dataset. The results were promising, while also highlighting the need for external validation before considering use in real clinical environments.

PROJECT 02

Breast Ultrasound AI Analysis

BUS-BRA • EfficientNet-B3 • Grad-CAM++ Explainability

The idea

This project explored whether a deep-learning model could distinguish between benign and malignant breast ultrasound lesions, while also investigating what the model was focusing on when making its prediction.

Instead of looking only at classification accuracy, I wanted to explore a second question: What is the model actually looking at when it makes a prediction?

What I built

I developed an EfficientNet-B3 based classifier using the BUS-BRA breast ultrasound dataset for benign versus malignant classification.

The project also included threshold selection, image-level evaluation, case-level evaluation, confidence analysis, and Grad-CAM++ explainability. Model attention was quantitatively compared with the available reference lesion masks.

Dataset BUS-BRA
Model EfficientNet-B3
Explainability Grad-CAM++

Image-level results

88.35% Accuracy
81.90% Precision
83.50% Recall
82.69% F1-Score
0.9364 ROC-AUC

Case-level results

90.00% Accuracy
81.67% Precision
89.09% Recall
85.22% F1-Score
0.9505 ROC-AUC

Why Grad-CAM++?

A classification result alone does not show which part of an image influenced the model. Grad-CAM++ was therefore used to visualize the regions receiving the model's attention.

I also compared the generated attention maps with the annotated lesion regions to investigate how closely the model's attention aligned with the actual lesion area.

Beyond the prediction

This project became an exploration of more than simply achieving a classification score. It allowed me to investigate model behaviour, confidence, explainability, and the difference between image-level and case-level evaluation.
